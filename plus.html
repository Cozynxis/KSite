HOE DE DEMO WERKT

Plus zonder backend testen

Wanneer je de demo activeert, schrijft KSite simpelweg een lokale waarde naar je browseropslag.

De lessenpagina leest die waarde uit en ontgrendelt vervolgens de Plus-modules. Het dashboard doet dezelfde controle voordat de inhoud zichtbaar wordt.

Dit is handig om de interface te testen op GitHub Pages, maar het is geen veilig betalingssysteem voor een echte commerciële website.

TECHNIEK

localStorage

De Plus-status blijft bewaard totdat lokale browserdata wordt verwijderd of de demo wordt uitgeschakeld.

VEILIGHEID

Geen geheime keys

Een statische GitHub Pages-site mag nooit geheime betaal- of databasekeys in JavaScript bevatten.

FAQ

Veelgestelde vragen

Kost deze Plus-demo geld?

Nee. Deze versie bevat geen echte betaling en activeert alleen een lokale demo-status.

Blijft Plus actief?

Ja, binnen dezelfde browser zolang de localStorage-data blijft bestaan.

Werkt dit op GitHub Pages?

Ja. De volledige demo gebruikt alleen HTML, CSS en JavaScript.

Kan er later echte betaling komen?

Ja, maar dan is een beveiligde backend en een betaalprovider nodig.
