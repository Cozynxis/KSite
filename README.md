# KSite — Kietel Site

KSite is een moderne, educatieve GitHub Pages-website over tast, kietelen, huidreceptoren, zenuwen, hersenen, reflexen, lachen en persoonlijke grenzen.

## Pagina's

- `index.html` — uitgebreide homepage
- `ontdek.html` — interactieve kennisbank met kenniskaarten
- `lessen.html` — 8 educatieve modules met XP en lokale voortgang
- `quiz.html` — interactieve kennisquiz
- `profiel.html` — profiel, XP, niveau en voortgang
- `plus.html` — KSite Plus demo-abonnement
- `plus-dashboard.html` — exclusieve Plus dashboardomgeving

## Techniek

De site gebruikt alleen HTML, CSS en JavaScript en is daardoor geschikt voor GitHub Pages. Dark/light mode, XP, lesvoortgang en Plus-status worden met `localStorage` in de browser opgeslagen.

## Plus demo

Er zit bewust geen echt betalingssysteem in de statische GitHub Pages-versie. De Plus-knop activeert alleen lokaal de demo. Voor echte accounts en betalingen is later een beveiligde backend en betaalprovider nodig.

## GitHub Pages

Zet in de repository-instellingen GitHub Pages op `Deploy from a branch`, branch `main`, map `/ (root)`. Daarna wordt `index.html` automatisch als startpagina geladen.

## Educatieve insteek

KSite geeft algemene educatieve informatie. Persoonlijke gevoeligheid verschilt. Aanraking hoort vrijwillig te zijn; een stop- of nee-signaal betekent altijd stoppen.
